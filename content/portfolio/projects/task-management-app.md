## Overview
A comprehensive task management application that allows teams to collaborate in real-time, organize tasks into projects, and track progress with visual analytics.

## Features
- Create and organize tasks with categories
- Assign tasks to team members
- Real-time collaboration with WebSocket updates
- Due date reminders and notifications
- Progress tracking and analytics dashboard
- Export tasks to PDF or CSV

## Technologies
Backend built with Go and PostgreSQL database. Frontend built with React for a smooth user experience with real-time updates via WebSocket.
