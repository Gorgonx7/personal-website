## Overview
A beautiful and responsive weather dashboard that provides real-time weather data, hourly forecasts, and weather alerts for any location around the world.

## Features
- Search weather by city name or coordinates
- Hourly and weekly forecasts
- Weather alerts and warnings
- Dark mode support
- Responsive mobile design
- Saved locations history

## Technologies
Built with React and TypeScript, using a public Weather API for data and Tailwind CSS for styling.
