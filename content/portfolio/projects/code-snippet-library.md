## Overview
A comprehensive code snippet library where developers can browse, search, and save useful code snippets across multiple programming languages and frameworks.

## Features
- Search and filter snippets by language, framework, and tags
- Save favorite snippets to personal library
- Syntax highlighting for all languages
- Copy to clipboard functionality
- Contribute new snippets
- Comments and ratings on snippets

## Technologies
Built with Vue.js for the frontend, Algolia for lightning-fast search, and Firebase for backend and authentication.
